# Project Drift 2.0 — 3D Mobile & Android APK

Incluye los 5 modos de manejo (Arcade, Drift, Pro Arcade, Pro Drift, Racing), 4 autos JDM esculpidos en Three.js con tuning en vivo (Camber, Altura, Ángulo de giro, Turbo, Widebody, Alerón, Neón), 3 mapas (Puerto Industrial, Akina Touge Nocturno, Drift Park), modo foto 360° y HUD adaptable a Vertical y Horizontal.
